# Board filtering and Card preview V2 (P3-13)

This client integrates the [P3-07 Board-local filtering and summary contract](../backend/board-card-filtering.md). Filters are encoded in the Board URL and applied explicitly. The API supplies filtered pages and their total; the separately ordered Column list determines layout. Reordering is disabled while filtering because a page is not the full order. Column deletion is also disabled in that state. Clearing filters restores the existing unfiltered loading and drag behavior.

Filtered and summary caches include the authenticated session generation, Board ID, and query inputs. Card, label, checklist, attachment and comment mutations invalidate affected filtered pages or summaries even when realtime is unavailable. Shared Board links include only validated filter fields. The Board requests preview summaries in batches of up to 100 displayed Card IDs. Catalog labels, checklist progress, active attachment counts, persisted comment counts, dates, and authorized roster entries are shown only when supplied. Dates use account preferences and the shared due-state rule. Existing Board and Card access checks remain authoritative. Card route navigation retains the search string.

The URL date range is expressed in UTC, with an inclusive start and exclusive end. The filter API combines facets with AND and uses OR within label and assignee facets. Filtered result pages use the server total; their displayed Column counts represent cards on the current page.

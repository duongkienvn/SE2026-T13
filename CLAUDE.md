# CLAUDE.md

Before making changes, read and follow:

- `AGENTS.md`
- `README.md`
- `docs/project-overview.md`
- relevant files under `docs/architecture/`

`AGENTS.md` contains the repository-wide engineering rules.

## Important

- Follow the existing pnpm monorepo structure.
- Do not introduce architectural changes without discussion.
- Keep changes scoped to the requested task.
- Do not push directly to `main`.
- Do not commit, push, merge, or modify remote branches unless explicitly requested.
- Run the relevant checks defined in `AGENTS.md` before finishing.

If code and documentation conflict, report the discrepancy instead of silently redesigning the system.
